# NESTOR Bin Mapper

Turns R&S NESTOR scanner recordings (.db files) into ranked bin maps (KMZ for Google Earth), with a text report, a CSV of every ranking, and a replay of the drive.

## Download

**[Get the latest version](../../releases/latest)**, then pick the zip for your computer:

| Computer | File |
|---|---|
| Windows 10 / 11 | NESTOR_Bin_Mapper-Windows.zip |
| Mac with Apple chip (M1 and newer) | NESTOR_Bin_Mapper-macOS-AppleSilicon.zip |
| Mac with Intel chip | NESTOR_Bin_Mapper-macOS-Intel.zip |

No installation, admin rights or Python needed.

**Windows:** unzip anywhere, open the folder and double-click **NESTOR Bin Mapper.exe**. First time only: "Windows protected your PC" → **More info** → **Run anyway**.

**Mac:** unzip, drag **NESTOR Bin Mapper.app** anywhere and double-click it. First time only: **System Settings → Privacy & Security** → scroll down → **Open Anyway**.

The app is not code-signed, which is why these one-time warnings appear.
